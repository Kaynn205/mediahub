5.
Le code 201 est cohérent avec ce que nous avons vu en cours. L’identifiant (id) a été ajouté automatiquement, car il ne nous appartient pas de le définir : c’est au serveur de le générer et de le gérer.

8.
Nous obtenons un code de statut 201, mais le corps de la réponse est vide. Cela correspond à une réponse indiquant qu’une ressource a été créée. Attention, le code 201 est généralement associé à une requête POST plutôt qu’à une requête GET.
